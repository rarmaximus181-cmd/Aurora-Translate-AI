# Aurora Translate 2

- Redesigned conversation workspace, model selector, task suggestions, and advanced controls.
- Stronger local AI model option, improved response styles, larger conversation context, and optional model reasoning.
- Animated startup with a reduced-motion option.
- Optional Troll display rewrites the literal phrase “this is not allowed” on screen. Original answers remain available and are used for conversation history and speech.
- GitHub update checks, required-update prompts, SHA-256 verification, and automatic release builds after changes are pushed to main.
- Existing translation, PNG/GIF themes, offline voices, voice-model import, Discord profiles, and history remain available.

Install this version once to enable the updater. Earlier builds did not include an updater and need a manual upgrade. Future mandatory releases are required once the app learns that a newer release is available. If GitHub cannot be reached and no required update was previously recorded, local features can still open.
